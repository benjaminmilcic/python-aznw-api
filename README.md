This service is made with FastAPI and LiteLLM. It answers questions about me and my website with RAG over a knowledge base and tool calling for live data.

The repository is public, because I made this website to demonstrate my skills.

The backend that uses this service can be viewed here: [Backend repository](https://github.com/benjaminmilcic/nest-aznw-api). The frontend with the chat can be viewed here: [Frontend repository](https://github.com/benjaminmilcic/aznw-routes). Both are public, too.
